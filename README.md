# Odin Recipes

This is my first project from The Odin Project.

## About

Odin Recipes is a basic recipe website built using HTML.

The website contains a main recipes page with links to individual recipe pages.

## Skills Demonstrated

* Creating a basic HTML webpage
* Using headings, paragraphs, and lists
* Adding images to webpages
* Creating links between webpages
* Organising files and folders
* Using Git and GitHub
